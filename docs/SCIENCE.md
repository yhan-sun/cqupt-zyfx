# 科学跑步内容与版式

六个专题：跑前热身、跑后拉伸、训练方法、力量、营养补给、恢复安全。总览页提供专题入口、动作预览、30项静态索引及关键词筛选；正文采用桌面侧栏、手机横向栏目导航、本页目录、表格、动作卡与就近引用。资料页单独列出证据类型和图源许可。

## 内容原则

使用一般健康成年人科普口径，不是诊断、康复或个体训练计划。注明资料核对日期，不把资料核对写成临床审核。常用训练解释目的、强度、教学示例与误区；不照抄商业或赛事机构完整课表。示例明确由本站编排，不能承诺防伤、减脂或成绩提升。

补给表需保留运动时长、强度和耐受条件。不要把30–60g/h或90g/h写成所有跑者的最低摄入量。区间相互重叠，不以分钟边界强制切档。不给通用盐丸剂量，不把电解质当作能量，也不把额外补盐当成过量饮水的解法。换算器不推断个人需求。

## 动作与授权

12个原始GIF：11个CDC基础动作、1个Wensceslao高抬腿。4幅Everkinetic分解图：臀桥与侧平板各两幅。共14个动作。CDC原始面向老年人基础力量活动，本站仅作动作识别；带负重的图片明确提醒不照搬负重。动态图速度不是处方。

图源登记原始URL、文件页、作者、许可、SHA-256、像素与帧数。下载校验与缓存校验使用同一哈希，全部帧实际解码，出错即停止。衍生静态帧和格式转换遵循原许可。所有图在构建后同站托管，不热链。NHS和AAOS未明确开放的媒体只放原站链接。

默认静止、按需播放、同页单一动图、切换标签停止。低动态偏好不自动开启任何动图；主动点击仍可播放和停止。静态页与动作要点无需JavaScript可读，计算器禁用脚本时显示公式。
