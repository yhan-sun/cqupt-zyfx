## 必须保持的事实边界

- `2024 年首次出征`只表示公众号所述「自邮飞翔马拉松战队」首次出征，不能据此推断跑步爱好者协会、重邮约跑团或自邮飞翔的成立年份。
- `478 名志愿者`是文章记录的重庆邮电大学赛事志愿者总数，不是跑团成员数。
- `报名奖第 4`是 2024 夜跑半马的团队报名奖，不是竞速团体名次。
- 2025 秋招文章中的周一、周三、周六训练结构属于历史记录。网站必须同时显示年份和「不是当前课表 / 不代表当前训练时间」等提示。
- 旧文章中的招新截止日期、入群二维码、手机号、成绩门槛不作为当前招新入口，不写回首页报名区域。
- 公众号里公开的个人姓名、5K / 全马 / 半马个人成绩表不需要复制到官网。展示团队层面的聚合事实即可。
- 2027 等未来目标属于文章中的愿景，不等于赛事已经报名、成行或取得名次。

## 更新方式

1. 新文章先核对账号、发布日期、赛事日期和原文上下文。
2. 只把能够从原文直接支持的事实写入 `data/official-posts.json`，不要根据标题补全缺失名次或人数。
3. 数字必须带语义，例如「团体计分总用时」「学校志愿者人数」「报名奖」，不能只留一个数字让页面自行解释。
4. 新图片写入 `data/official-media.json`，保存来源文章、原始 URL、尺寸与 SHA-256；构建不接受来源字节静默变化。
5. 新增或改变当前招新、当前训练时间等时效信息时，必须单独核实当前公告，不能沿用历史文章。
6. 运行 `npm test`、`npm run build`、`tests/browser.py`、`tests/science_browser.py`、`tests/official_browser.py` 后再发布。

`club.html` 是构建生成页面，不要直接编辑。归档页、首页跑团足迹、科学跑步历史训练引用与来源页都由 `scripts/official-build.mjs` 从上述数据生成或注入。
