## 必须保持的事实边界

- `2024 年首次出征`只表示公众号所述「自邮飞翔马拉松战队」首次出征，不能据此推断协会、重邮约跑团或自邮飞翔的成立年份。
- `478 名志愿者`是重庆邮电大学赛事志愿者总数，不是跑团成员数。
- `报名奖第 4`是 2024 夜跑半马的团队报名奖，不是竞速团体名次。
- 2025 秋招文章中的周一、周三、周六训练结构属于历史记录，页面必须显示年份和「不是当前课表 / 不代表当前训练时间」。
- 旧招新截止日期、旧二维码、手机号和成绩门槛不作为当前入口。
- 公众号里的个人姓名及个人 5K / 全马 / 半马成绩表不复制到官网，只展示团队层面的聚合事实。
- 2027 等未来目标属于文章愿景，不等于赛事已经报名、成行或取得成绩。
- 图片只用于记录公开的团队/活动场景，不根据照片推断任何人的姓名、成绩、健康状况或身份。

## 当前 20 张跑团图片

筛选优先级从“有一张代表图”调整为“能讲出跑团文化”：

- **校园训练**：太极运动场集体跑、训练合影、5K 测试及起跑准备。
- **一起出发**：清远、重庆、贵阳、接力赛和夜跑中的赛前集结、团队旗帜与赛道场景。
- **赛道之外**：跑友自拍、赛后交流、跨届校友和团队合影。

没有选择旧招新二维码、联系方式截图、路线截图或个人成绩截图。`data/club-culture.json` 维护年度章节、每篇文章的照片组合和影像分类；同一批 20 张跑团图片在 `赛事与足迹` 里用于照片叙事，在 `跑步影像` 里可以完整筛选浏览。

公众号图片**未发现开放许可**，版权仍归原权利人。署名、原文入口、哈希校验和本地转码都不等于获得开放授权；正式运营方仍应确认转载与肖像使用范围，或逐步替换为取得授权的跑团自有原图。

## 更新方式

1. 新文章先核对账号、发布日期、赛事日期和原文上下文。
2. 只把原文直接支持的事实写入 `data/official-posts.json`。
3. 数字必须带完整语义，例如「团体计分总用时」「学校志愿者人数」「报名奖」。
4. 新图片写入 `data/official-media.json`，保存来源文章、原始 URL、尺寸与 SHA-256；源字节变化必须重新审核。
5. 图片加入文化叙事时同步修改 `data/club-culture.json`，明确属于训练、赛事、团队或交流哪一类。
6. 当前招新、当前训练时间等时效信息必须单独核实，不能从历史文章自动继承。
7. 运行 `npm test`、`npm run build` 和 `tests/structure_browser.py` 后再发布。

`club.html` 和 `gallery.html` 都是构建产物，不要直接编辑。最终文化版式由 `scripts/culture-build.mjs` 在基础信息架构之后生成。
