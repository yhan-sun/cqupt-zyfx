# 内容交接

## 已有内容

名称关系依据委托方提供；两届校园马拉松简介依据公开报道；公开成绩页仅用于验证“重庆邮电大学－自邮飞翔”及二队名称。完整来源和许可说明在 sources.html。

校园赛事没有被标成协会举办。路线是跑步灵感，不是实测地图。配速是数学换算，不是成绩预测。摄影素材没有被冒充社团成员或赛事实拍。

## 运营方需确认的内容

1. 本学期入群二维码或正式招新链接、有效期、管理方。
2. 日常活动时间、集合点、恶劣天气取消渠道与组织负责人。
3. 协会原创会徽和可公开使用的成员摄影，取得摄影和肖像使用授权。
4. 对外发布的成立年份、章程和社交账号；未核实前不展示。

不需要在公开仓库提交个人手机号、学号、住址或报名表数据。

## 启用招新

编辑 data/site.mjs 的 site.join。只有管理方确认链接且为 HTTPS 时，才能设置 verified:true 和 url。更新 notice 与 label，同步 FAQ 说明和核实日期。二维码图片应有截止日期和文字链接替代，不使用随机生成或示意二维码。

本网站没有报名后端。若接入第三方表单，必须配置真实地址，提供数据用途说明；不能在本地弹出“报名成功”假装提交。

## 发布检查

确认 Pages Source 已设置 GitHub Actions。等待同一 main SHA 的 build 和 deploy 全部成功，打开实际地址确认照片、菜单、手记、路线与配速工具，尤其检查项目子路径而不是根域名。更新内容后仍须通过测试。

运行截图和测试报告从 Actions 的 browser-evidence 获取；可独立托管的静态产物从 website 获取。README 的预期 URL 不是已部署证据。
