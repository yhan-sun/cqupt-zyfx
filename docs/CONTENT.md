# 内容与运营交接

## 最终信息架构

当前一级导航固定为：**首页 / 协会介绍 / 活动记录 / 相册 / 跑友风采 / 跑步指南 / 加入我们**。

“校园赛事”与“跑团足迹”不再作为两个一级栏目。`club.html` 同页呈现：

- 跑团公开足迹：委托方提供的 8 篇 `CQUPT自邮飞翔` 公众号记录；
- 校园赛事档案：2024、2025、2026 三届重邮人马拉松公开资料。

两类资料必须保持语义边界。校园赛事不能写成跑团主办；跑团成绩和成员数据只能按对应公众号文章日期与范围表述。

`news.html` 是旧栏目兼容入口，三个 `news/marathon-*.html` 正文继续保留。不要为了“合并栏目”删除可公开访问的历史文章 URL。

原“跑步服务”已从最终导航和首页撤下。除非用户重新明确要求，不恢复场地切换、配速工具或“跑步服务”一级栏目。加入页里原先指向跑步场景的入口现在应指向跑步影像。

## 跑步影像

`gallery.html` 是独立跑步照片页，当前 35 张照片组成如下：

- 20 张 `CQUPT自邮飞翔` 公众号资料图：跑团集结、校园 5K 测试、集体跑步、城市马拉松、高校联赛、接力与夜跑；
- 9 张协会侧本次提供的校园训练、校内赛事、跑友交流与赛事照片；
- 6 张校园赛事图：2025 重邮人马拉松现场和 2024 起跑、接力、跑者、赛前、沿途影像。

每张照片必须同时有：已知时间/类别、标题、简短场景说明、原始出处。图片说明只描述资料能够支持的场景，不依据照片猜测具体人物身份、成绩、健康状态或成员关系。

公众号图片未发现开放许可，版权仍归原权利人。校园赛事图片沿用 `data/media.json` 的权利说明。署名和原文链接不等于开放授权；正式运营前仍应确认转载、摄影与肖像使用范围，或逐步替换成已获授权的跑团自有照片。

首页只展示少量跑步影像预览，不再复制完整相册。

## 跑友风采

`runners.html` 展示由跑友本人确认的资料。当前登记胡钢：2025级自动化学院、5000m PB 17:24、10000m PB 36:35、2025璧山半马 1:20:57，个人宣言为“日拱一卒，功不唐捐”；俞沛君：2023级生命健康信息学院、5000m PB 17:59、半马 1:31:52、全马 3:48:00，个人宣言为“繁霜尽是心头血，洒向千峰秋叶丹”；杨昊贤：2023级国际学院、5000m PB 17:30、2025璧山马拉松（半马） 1:21:30、2025重庆马拉松（全马） 2:59:47，个人宣言为“我是奶龙！我就是奶龙！！！”。胡钢使用的校园跑道照片登记在 `data/member-media.json`，俞沛君和杨昊贤的跑友个人照片登记在 `data/runner-profiles.json` 的 `photos`，人物字段与展示范围也登记在该文件。

该栏目用于认识一起跑的人，不是完整或实时的队员名册，也不做横向排名。每位跑友沿用本人资料、个人记录、个人宣言和照片来源的同一结构；新增资料前必须由本人提供或明确确认。人物资料与照片不因署名而获得开放许可，来源说明保留在 `sources.html#runner-profiles`。

二维码解析为 QQ 加群链接 `https://qm.qq.com/q/9rKOuWR8Ag`。当前加入资料统一维护在 `data/join.json`，站内二维码为对应同一目标的 `assets/join-qq.svg`。页面必须同时保留直接 QQ 入口和群号文字备用方式。

旧公众号招新二维码、旧截止日期、历史成绩门槛和过去训练时间不能覆盖当前加入资料。群号、链接、二维码、群名或参与说明变化时，应重新核实并更新 `reviewedAt`。

群入口有效也不意味着活动有固定时间。集合点、配速分组、训练内容和赛事报名以群内当期通知与赛事主办方规则为准。本站没有入群表单或报名后台，不收集 QQ 号、手机号、学号、健康信息或赛事报名资料。

## 修改与发布

基础赛事内容修改 `data/content.json` / `data/media.json`；公众号档案修改 `data/official-posts.json` / `data/official-media.json`；跑友资料修改 `data/runner-profiles.json`；当前加入信息修改 `data/join.json`。

最终页面结构由 `scripts/build.mjs` 统一从模型渲染。不要直接编辑 `dist`，也不要仅修改生成后的页面。

发布前至少完成：

```text
npm test
npm run build
python tests/structure_browser.py
```

浏览器检查应覆盖 320 / 390 / 768 / 1024 / 1440 px、移动菜单、无 JavaScript、旧赛事直达 URL、35 张跑步影像、跑友风采、图片同站加载、来源链接、科学跑步和 QQ 加入入口。合并到 `main` 后等待 Pages deploy 成功，并检查公开的 `club.html`、`gallery.html`、`runners.html`、`science.html`、`join.html` 与兼容 `news.html`。
