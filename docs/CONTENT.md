2026年9月7日，跑团提供了「重邮约跑团」QQ 群二维码和群号 `468686951`，并给出定位：为重邮学子搭建的跑步交流平台，不定期组织交流活动，鼓励校内跑步打卡，并在合适机会交流、同行参加校外马拉松赛事。

当前加入资料维护在 `data/join.json`，二维码为 `assets/join-qq.jpg`。二维码和群号属于当前可公开参与入口，不再使用旧公众号招新二维码、旧截止日期、个人联系方式或历史成绩门槛。

即使群入口有效，也不能把活动频率、集合地点、训练时间或赛事报名写成固定安排。具体活动以群内当期通知和赛事主办方规则为准。二维码失效时仍显示群号作为文字备用入口；如果群号也失效，应先向跑团核实再更新网站。

本站没有入群表单或报名后台，不收集 QQ 号、手机号、学号、健康信息或比赛报名资料。

## 上线前需要运营方确认

官网和新闻图未发现开放许可。署名不是授权。正式运营前确认学校宣传部门或相关权利人的使用范围；不能确认时改用取得摄影和肖像授权的社团自有照片。本站来源页如实说明这一边界，不给这些照片错误附加开源许可。

尚缺可公开的自有会徽及更多取得摄影、肖像授权的日常活动照片。不要在公开仓库上传学生手机号、学号、报名资料等。

## 修改资料

编辑 data/content.json 的 stories，并补齐时间、来源、摘要和配图说明。所有页面在构建时从同一份数据生成，无需同步两份新闻内容。

加入信息编辑 `data/join.json`。QQ群号、二维码、群名或适用人群发生变化时必须重新向跑团确认，并同步修改核对日期。不要用历史公众号招新材料自动覆盖当前群入口。

`data/content.json` 的 join.url 仍只用于未来经核实的 HTTPS 招新链接；没有真实链接时保持关闭。静态站没有报名后端，不能用本地提示冒充报名成功。

图片补充需填写 data/media.json 的 title、credit、source、url、year 和 license。不要以今天日期代替无法确认的拍摄年份。首屏横幅建议长边至少1600像素；小图不能被当成高清大图。

## 发布核验

npm test → npm run build → 浏览器检查全部通过，再执行 main 部署。确认 Pages 首次管理员设置，等待 deploy 成功并检查实际项目子路径。可下载 Actions 的 website、interactive-preview 和 browser-evidence 产物。

加入体验还需检查：`join.html` 可直接刷新、二维码同站加载、QQ群号有文字备用、320px 手机无横向溢出、无 JavaScript 时二维码和群号仍可读、复制按钮在无脚本时不形成死控件。
